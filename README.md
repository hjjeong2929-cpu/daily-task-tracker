# ✅ Daily Task Tracker

GitHub만으로 돌아가는 개인 할일 관리 시스템입니다. "깜빡하고 놓침 / 우선순위가 안 잡힘 / 시작만 하고 끝을 못 봄" 이 세 가지를 GitHub Issues + Actions + Projects 조합으로 해결합니다.

## 전체 그림

| 문제 | 해결 방법 |
|---|---|
| 할일을 깜빡하거나 잃어버림 | 매일 아침 "오늘의 할 일" 이슈가 자동 생성되고, 나에게 할당되어 휴대폰 푸시로 옴 |
| 할일이 많아서 우선순위가 안 잡힘 | P1(오늘 반드시)/P2/P3 라벨 + Projects 보드에서 라벨별로 그룹핑해서 확인 |
| 시작만 하고 끝을 못 봄 | 3일 넘게 방치된 이슈에 자동으로 넛지 댓글, 7일 넘으면 우선순위 자동 승격(P1) |
| 반복되는 일을 매번 다시 입력 | `tasks.yml`에 한 번만 등록하면 자동으로 이슈 생성 |

## 할일을 넣는 두 가지 방법

**1) 반복되는 일** → `tasks.yml`에 등록 (아래 예시 참고). 매일 아침 자동으로 이슈가 만들어집니다.

**2) 1회성 일** → GitHub에서 그냥 이슈를 새로 만들면 됩니다. 마감일을 챙기고 싶으면 제목 끝에 `(YYYY-MM-DD)`를 붙이세요.

```
보고서 제출 (2026-09-05)
```

이렇게 해두면 마감일이 되거나 지났을 때 자동으로 "오늘의 할 일"에 포함됩니다. 급한 일이면 라벨을 `P1`로 붙여주세요.

## 매일 자동으로 일어나는 일

- **아침 06:00 (KST)**
  1. `tasks.yml`에서 오늘 해당하는 반복 작업을 이슈로 생성 (나에게 자동 할당)
  2. 연체된 일 + 오늘 마감인 일 + P1 라벨이 붙은 일을 모아 **"📋 오늘의 할 일 (날짜)"** 이슈 하나로 정리 (역시 나에게 자동 할당)
- **밤 23:50 (KST)**
  1. 3일 넘게 열려있는 이슈에 넛지 댓글 (7일 넘으면 우선순위를 P1로 자동 승격)
  2. 그날 마감이었던 일들의 완료율을 집계해서 아래 통계와 스트릭을 갱신

즉, 할 일은 두 가지뿐입니다 — **아침에 온 알림 확인하기 / 끝내면 이슈 Close 하기.**

## 폴더 구조

```
.
├── tasks.yml                          # 반복 작업 목록 (직접 편집)
├── data/history.json                  # 일별 완료 기록 (자동 생성/갱신)
├── scripts/
│   ├── ghutil.py                      # 공용 GitHub API 헬퍼
│   ├── create_recurring_issues.py     # 오늘의 반복 이슈 생성
│   ├── daily_digest.py                # 오늘의 할 일 요약 생성
│   ├── nudge_stale_issues.py          # 방치된 이슈 넛지 + 우선순위 승격
│   └── update_stats.py                # 완료율 집계 + README 갱신
└── .github/workflows/
    ├── morning.yml                    # 매일 06:00 KST 실행
    └── evening.yml                    # 매일 23:50 KST 실행
```
