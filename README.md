# ✅ Daily Task Tracker (v2)

GitHub만으로 돌아가는 개인 할일 관리 시스템입니다. 화면정의서(FigJam) 기준 v2로, **우선순위 기능은 없고** 대신 아래가 새로 생겼습니다.

- 홈 화면 = **월 캘린더 + 선택한 날짜의 할일 리스트**가 하나로 합쳐진 화면
- **즐겨찾기** — 자주 쓰는 할일 문구를 저장해뒀다가 탭 한 번으로 추가
- **반복 할일** — 요일 지정 + 기간(옵션) 지정 동시 지원
- **Period 할일** — 기간을 등록해두면 그 기간의 **마지막 날에만** 목록에 나타나는 유형
- **하루 2번 고정 시각 푸시** (오후 4:30, 오후 9:30) — 그 외 추가 알림 없음
- 미완료 항목은 다음 날로 넘어가지 않고 **그 날짜에 그대로 남음** (나중에 날짜를 찾아가서 체크 가능)

## 화면 (index.html)

GitHub Pages로 배포하는 `index.html` 하나가 앱 전체입니다.

- 상단 캘린더: 기본 할일은 점(●), Period 할일은 기간에 걸친 막대로 표시. 날짜를 탭하면 그 날짜의 리스트로 즉시 전환됩니다 (화면 이동 없음).
- 체크박스: 손가락으로 누르기 편하게 44×44 히트 영역으로 키워뒀어요.
- 자동 생성된 반복 항목 중 "오늘은 해당 없음"인 건 ✕로 지울 수 있어요. 그날 인스턴스만 없어지고, 반복 규칙 자체는 그대로예요.
- 하단 입력창 + "즐겨찾기 ▾" 버튼으로 할일을 추가합니다. 즐겨찾기 항목을 탭하면 바로 추가돼요.
- "+ Period 할일 등록", "+ 반복 할일 등록" 두 폼을 펼쳐서 새 항목을 등록할 수 있어요.

## 데이터가 저장되는 곳

| 파일 | 내용 |
|---|---|
| `data/recurring_rules.json` | 반복 할일 규칙 (제목, 요일, 기간 옵션) |
| `data/favorites.json` | 즐겨찾기 문구 목록 |
| `data/history.json` | 일별 완료 기록 (자동 생성/갱신) |
| GitHub 이슈 | 실제 할일 하나하나 (제목 끝의 `(YYYY-MM-DD)`가 그 할일이 속한 날짜) |

**반복 할일** 예시 (`data/recurring_rules.json`):

```json
{
  "id": "exercise",
  "title": "운동 30분",
  "days": ["mon", "wed", "fri"],
  "start_date": "2026-09-01",
  "end_date": "2026-09-30"
}
```

이렇게 등록하면 9월 한 달 동안 매주 월·수·금마다 각각 "운동 30분 (그날짜)"라는 **개별 기본 할일**이 자동 생성됩니다. (Period 할일과는 다른 개념이에요 — Period 할일은 등록된 기간의 마지막 날에 딱 한 번만 나타나는 별개 기능입니다.)

## 매일 자동으로 일어나는 일

- **오전 06:00 (KST)** — 오늘 해당하는 반복 할일 생성 + "📋 오늘의 할일 (날짜)" 이슈 생성
- **오후 4:30, 오후 9:30 (KST)** — "오늘의 할일" 이슈에 `@내아이디` 셀프 멘션 댓글을 남겨서 GitHub 앱 푸시를 트리거. 남은 할일이 없으면 축하 문구로 대체돼요. **이 2번 외에는 어떤 알림도 발송되지 않습니다.**
- **밤 23:50 (KST)** — 그날 완료율을 집계해서 스트릭/통계 갱신

## 왜 "댓글 + 셀프 멘션"인가요?

GitHub 모바일 앱은 4가지 이벤트(멘션, 배정, 리뷰 요청, 배포 승인)에만 푸시를 보내고, 단순 댓글에는 푸시가 안 갈 수 있어요. 그래서 댓글을 남길 때 스스로를 `@멘션`해서 "멘션" 이벤트로 잡히게 만드는 방식을 씁니다. 폰 배너 자체는 GitHub이 정한 짧은 문구("OO님이 멘션했습니다")일 수 있고, 실제 할일 목록은 알림을 눌러 댓글을 열어야 보여요.

## 폴더 구조

```
.
├── index.html                         # 앱 화면 (GitHub Pages로 배포)
├── data/
│   ├── recurring_rules.json           # 반복 할일 규칙
│   ├── favorites.json                 # 즐겨찾기 문구
│   └── history.json                   # 일별 완료 기록 (자동 생성/갱신)
├── scripts/
│   ├── ghutil.py                      # 공용 GitHub API 헬퍼
│   ├── create_recurring_issues.py     # 오늘의 반복 할일 인스턴스 생성
│   ├── daily_digest.py                # "오늘의 할일" 이슈 생성
│   ├── notify_push.py                 # 4:30 / 9:30 셀프 멘션 푸시
│   └── update_stats.py                # 완료율 집계 + README 갱신
└── .github/workflows/
    ├── morning.yml                    # 매일 06:00 KST
    ├── push_notify.yml                # 매일 16:30, 21:30 KST
    └── evening.yml                    # 매일 23:50 KST
```
